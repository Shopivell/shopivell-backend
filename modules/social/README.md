# Social Module

## Overview
Social media integration and management.

## Features
- Multi-platform posting
- Account connection
- Post scheduling
- Engagement tracking
- Analytics

## Supported Platforms
- Facebook
- Instagram
- Twitter/X
- TikTok
- LinkedIn

## Endpoints
- `POST /social/connect` - Connect account
- `GET /social/accounts` - List accounts
- `POST /social/post` - Create post
- `GET /social/posts` - List posts
- `POST /social/schedule` - Schedule post
- `GET /social/analytics` - Get analytics

## Models
- SocialAccount
- SocialPost
- PostSchedule
