# Offers Module

## Overview
Special offers and deal management for stores.

## Features
- Flash sales
- Bundle deals
- Limited-time offers
- Seasonal promotions
- Deal scheduling

## Endpoints
- `POST /offers` - Create offer
- `GET /offers` - List offers
- `GET /offers/{id}` - Get offer details
- `PUT /offers/{id}` - Update offer
- `DELETE /offers/{id}` - Delete offer
- `POST /offers/{id}/activate` - Activate offer

## Offer Types
- Flash sale
- Bundle
- BOGO (Buy One Get One)
- Clearance
