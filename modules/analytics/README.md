# Analytics Module

## Overview
Comprehensive analytics and reporting for stores, products, and campaigns.

## Features
- Sales analytics and trends
- Product performance metrics
- Customer behavior analysis
- Campaign ROI tracking
- Revenue forecasting

## Endpoints
- `GET /analytics/dashboard` - Dashboard overview
- `GET /analytics/sales` - Sales metrics
- `GET /analytics/products` - Product performance
- `GET /analytics/customers` - Customer insights
- `GET /analytics/campaigns` - Campaign metrics

## Metrics Tracked
- Total revenue
- Order count
- Average order value
- Conversion rates
- Top products
- Customer retention
