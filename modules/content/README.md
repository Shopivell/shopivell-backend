# Content Module

## Overview
Content creation and management for social media and marketing.

## Features
- Blog post creation
- Social media content
- Content calendar
- Template management
- SEO optimization

## Endpoints
- `POST /content` - Create content
- `GET /content` - List content
- `GET /content/{id}` - Get content details
- `PUT /content/{id}` - Update content
- `DELETE /content/{id}` - Delete content
- `POST /content/{id}/publish` - Publish content

## Content Types
- Blog posts
- Social media posts
- Email templates
- Landing pages
