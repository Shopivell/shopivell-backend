# Stores Module

## Overview
Store management and configuration.

## Features
- Store creation
- Store settings
- Theme customization
- Domain management
- Store analytics

## Endpoints
- `POST /stores` - Create store
- `GET /stores` - List user stores
- `GET /stores/{id}` - Get store details
- `PUT /stores/{id}` - Update store
- `DELETE /stores/{id}` - Delete store
- `PUT /stores/{id}/settings` - Update settings
- `GET /stores/{id}/analytics` - Store analytics

## Models
- Store
- StoreSettings
- StoreDomain

## Store Types
- E-commerce
- Service
- Digital products
