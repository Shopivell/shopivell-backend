# Markets Module

## Overview
Marketplace and multi-vendor functionality.

## Features
- Marketplace listings
- Vendor management
- Product discovery
- Category browsing
- Search functionality

## Endpoints
- `GET /markets` - List marketplaces
- `GET /markets/{id}/products` - Browse products
- `GET /markets/categories` - List categories
- `GET /markets/search` - Search products
- `POST /markets/list` - List product in marketplace
