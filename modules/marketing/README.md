# Marketing Module

## Overview
Marketing tools and promotional features for stores.

## Features
- Discount codes
- Promotional campaigns
- Email marketing
- SMS campaigns
- Referral programs

## Endpoints
- `POST /marketing/discounts` - Create discount
- `GET /marketing/discounts` - List discounts
- `POST /marketing/email` - Send email campaign
- `POST /marketing/sms` - Send SMS campaign
- `GET /marketing/referrals` - Referral stats

## Discount Types
- Percentage off
- Fixed amount
- Free shipping
- Buy X get Y
