# WhatsApp Module

## Overview
WhatsApp Business API integration for customer communication.

## Features
- Message sending
- Template messages
- Automated responses
- Order notifications
- Customer support

## Endpoints
- `POST /whatsapp/send` - Send message
- `POST /whatsapp/template` - Send template
- `GET /whatsapp/conversations` - List conversations
- `POST /whatsapp/webhook` - Incoming webhook
- `PUT /whatsapp/settings` - Update settings

## Message Types
- Text
- Image
- Document
- Template (pre-approved)
- Interactive buttons

## Integration
- WhatsApp Business API
- Webhook for incoming messages
